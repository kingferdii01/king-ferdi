# KING FERDI — Professional Web3 Personal Website

Ready for GitHub + Vercel.

## Files
- `index.html` — website
- `profile.jpg` — profile image
- `favicon.svg` — browser favicon
- `og-image.svg` — social/WhatsApp preview image
- `robots.txt` — search crawler rules
- `sitemap.xml` — sitemap
- `vercel.json` — Vercel configuration

## GitHub
1. Create a new GitHub repository, e.g. `king-ferdi-website`.
2. Upload ALL files from this folder to the repository root.
3. Make sure `index.html` is directly in the root.

## Vercel
1. Open Vercel Dashboard.
2. Choose **Add New → Project**.
3. Import the GitHub repository.
4. Framework preset: **Other** (static site).
5. Leave Build Command empty.
6. Leave Output Directory empty.
7. Click **Deploy**.
